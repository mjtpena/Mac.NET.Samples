# Mac .NET Samples (macOS)

This repository is organized around modern .NET 10 capabilities on macOS, with focused samples that highlight UI, services, interop, graphics, and packaging.

## Goals

- Showcase modern macOS‑focused .NET techniques.
- Provide small, runnable samples with clear build/run steps.
- Keep legacy materials accessible but separated.

## Repository layout

- samples/ (new and modern samples)
- tooling/ (build, signing, packaging scripts)
- docs/ (guides and platform notes)
- templates/ (optional starter templates)
- assets/ (shared icons, screenshots)
- legacy/ (older samples retained for reference)

## Sample categories

- UI: MAUI, Mac Catalyst, AppKit interop
- Services: Minimal APIs, gRPC, Worker + launchd
- Native: NativeAOT CLI
- Graphics: Metal bindings
- Security: Keychain integration
