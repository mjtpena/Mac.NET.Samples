# Prerequisites

- macOS (latest stable recommended)
- .NET 10 SDK
- Xcode (latest stable)
- Xcode Command Line Tools
- For UI samples: macOS SDK + relevant workloads

## Suggested workloads

- MAUI (Mac Catalyst)
- macOS SDK (full)
- Mac Catalyst SDK (full)

## Signing & notarization

If you plan to run packaging or notarization samples, you’ll need:

- Apple Developer ID
- App‑specific passwords or API keys
- Notarytool credentials
